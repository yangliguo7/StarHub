## 📖 项目介绍

StarHub 是一个开源的 GitHub Stars 管理工具，帮助你高效管理和分类你的 GitHub 收藏。

### ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🔐 GitHub OAuth 登录 | 安全的 GitHub 账号授权登录 |
| 📊 Stars 一览 | 以卡片/列表形式展示所有收藏的仓库 |
| 🤖 AI 智能分类 | 支持多种 AI 模型自动分类你的 Stars |
| 🏷️ 自定义标签 | 手动创建和管理分类标签 |
| 🔍 智能搜索 | 按名称、描述、语言等快速搜索 |
| 🌙 暗色主题 | 支持亮色/暗色主题切换 |
| 🌐 多语言 | 支持中文和英文界面 |

### 🤖 支持的 AI 服务

| AI 服务 | 推荐模型 | 免费额度 |
|---------|----------|----------|
| Cloudflare Workers AI | gpt-5.5, llama-3-8b 等 | ✅ 每天 10,000 Neurons |
| OpenAI | gpt-4o-mini | ❌ 付费 |
| Claude | claude-3-5-sonnet | ❌ 付费 |
| DeepSeek | deepseek-chat | 💰 便宜 |
| 通义千问 | qwen-plus | 💰 便宜 |
| 智谱 AI | glm-4-flash | 💰 便宜 |

### 🛠️ 技术栈

- **前端**: Vue 3 + TypeScript + Vite
- **UI 组件**: Element Plus
- **状态管理**: Pinia
- **后端**: Cloudflare Pages Functions (Serverless)
- **部署**: Cloudflare Pages

### 第三步：配置 GitHub OAuth 应用

> 💡 **为什么需要 OAuth？** StarHub 需要通过 GitHub API 读取你的 Stars 列表，OAuth 是最安全的授权方式。

**3.2** 点击 **「OAuth Apps」**，然后点击 **「New OAuth App」**

## 🔧 常见问题

### Q1: 部署失败，提示 "npm error ERESOLVE"

**原因：** npm 依赖版本冲突

**解决：** 确保构建命令是 `npm install --force && npm run build`

### Q2: 登录报错 "Failed to exchange token"

**原因：** Client ID 或 Client Secret 不匹配

**解决：**
1. 检查 Cloudflare 环境变量是否正确
2. 检查 GitHub OAuth App 的回调 URL 是否正确（不要带 `/#/login`）
3. 重新生成 Client Secret 并更新环境变量

### Q3: 打不开网站

**原因：** DNS 解析问题（尤其在中国大陆）

**解决：**
```bash
# 方法1: 刷新 DNS 缓存
sudo dscacheutil -flushcache
sudo killall -HUP mDNSResponder

# 方法2: 手动指定 DNS
# 系统偏好设置 → 网络 → 高级 → DNS → 添加 8.8.8.8

# 方法3: 修改 hosts 文件
sudo bash -c 'echo "172.66.47.198 你的域名.pages.dev" >> /etc/hosts'
```

### Q4: AI 分类不工作

**解决：**
1. 进入设置页面
2. 配置 AI 服务（推荐 Cloudflare Workers AI，免费）
3. 填入 API Key 和 Account ID
4. 保存后重试
